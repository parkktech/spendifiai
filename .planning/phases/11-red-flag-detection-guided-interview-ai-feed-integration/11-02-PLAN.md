<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| document extraction → durable store | Extracted facts are untrusted until user-confirmed (Decision 4) |
| user A → user B facts | Cross-user disclosure risk on a shared facts table |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-02-01 | Repudiation | document-extracted fact auto-write | high | mitigate | Confirm-before-write gate: document_extraction rows stay is_current=false until confirmed_at set; never supersede user-entered facts |
| T-11-02-02 | Information Disclosure | cross-user fact read | high | mitigate | scopeForUser() + Policy on both models; encrypted value/attributes + $hidden |
| T-11-02-03 | Tampering | concurrent duplicate current rows | medium | mitigate | Partial unique index + DB transaction with SELECT FOR UPDATE in recordFact() |
| T-11-02-04 | Information Disclosure | GDPR deletion misses new tables | high | mitigate | cascadeOnDelete FKs on user_tax_facts + tax_profile_entities |
| T-11-02-05 | Information Disclosure | PII in queryable key | medium | mitigate | fact_key/label are non-PII namespaced strings; only encrypted value carries content |
| T-11-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero new packages (RESEARCH audit empty) |
</threat_model>
