# Phase 12 Plan 03: Report Engine Summary

**One-liner:** RPT-01–08 report engine — ranked 4-topical + 3-wrapper + year-end + glossary sectioned report generated by a ShouldBeUnique queued job, stored in OptimizationReport model, exported to PDF via dompdf, with per-section educational disclaimers, an approved RIA-reframed glossary, and numbers proven to originate from findings/engine (SAFE-03 gate green).

## What Was Built

### Task 1: OptimizationReport Model + Migration (RPT-01/02 Storage)

Additive migration creates `optimization_reports` table:
- `user_id` (FK, cascadeOnDelete), `tax_year` (integer)
- `sections` (JSONB) — assembled section objects containing finding IDs + prose, no dollar amounts
- `executive_summary` (TEXT nullable) — Claude-narrated overview
- `is_stale` (boolean default true), `stale_since` (timestamp), `rebuilt_at` (timestamp)
- `unique(user_id, tax_year)`, `index(user_id, is_stale)`

Model: `scopeForUser()` (T-12-03-02 cross-user isolation), `fetchOrInit()` (Pitfall 8 null guard), method-syntax `casts()`, `$hidden = []`.

### Task 2: Generator + Narrator (3rd Claude Call Site) + Job + Config

**OptimizationReportNarratorService** — mirrors NarrationService exactly:
- Same `callClaude()` retry loop, `max_tokens 256`, SAFE-01 system prompt
- Payload: `{section_title, findings:[{finding_type, severity, band, legal_basis}]}` — all monetary columns deliberately excluded (T-12-03-01)
- Prompt-injection defense: all user-derived content json_encode()'d, never interpolated into system prompt (T-12-03-03)
- 3rd and FINAL permitted Claude call site of the v2.1 milestone

**OptimizationReportGeneratorService**:
- Loads `OptimizationFinding::forUser()->where(tax_year)` 
- Groups into 4 topical sections via `config/optimization-report.php` `finding_type_to_section` map
- Ranks each section: severity tier (high=0, medium=1, low=2) then `estimated_value_cents` DESC — READ only, never assigned (SAFE-03 gate green)
- 4 topical sections: deductions, taxes, filings, retirement_401k
- 3 RPT-06 wrapper sections: documents_missing, needs_professional_review, what_we_refused (WHAT+WHY only, never HOW)
- RPT-08 year-end section: findings with deadline metadata grouped by Dec-31/Jan-15/April; "commonly reviewed before year end" framing, no pressure language
- RPT-07 glossary section: 11 approved educational entries; 5 RIA-reframed lines carry `[default ruling — owner review pending]` annotation
- Every section carries `disclaimer` string (RPT-03 persistent)
- Narrates each topical section and executive summary via NarratorService
- Upserts `OptimizationReport` via `updateOrCreate(['user_id','tax_year'])`

**GenerateOptimizationReport** job:
- `ShouldQueue + ShouldBeUnique` — prevents thundering-herd rebuilds (Pitfall 4)
- `uniqueId()` = `"{userId}:{taxYear}"`
- `tries=3, timeout=300, onQueue('optimization')`
- Memory guard: `ini_set('memory_limit', '512M')` in `handle()` (Pitfall 5)
- `failed()` logs error

**config/optimization-report.php**: section definitions, finding_type→section map, severity ordering, specialist bands, RPT-03 disclaimer text, RPT-07 glossary lines (with annotations), RPT-06 refusal registry, RPT-08 year-end framing config.

### Task 3: PDF Export + Blade View + Disclaimer + PDF Smoke Tests (RPT-03/04)

**OptimizationReportExportService**:
- Mirrors `TaxExportService::generatePDF()` exactly: `ini_set('memory_limit','512M')` → `Pdf::loadView('pdf.optimization-report', $data)` → `->setPaper('letter','portrait')` → `->save($path)`
- Flattens sections array before Blade (no heavy nested loops, reduces dompdf memory pressure)
- RuntimeException if file missing after save
- Storage: `local/optimization-reports/{user_id}/OptimizationReport_{year}_{timestamp}.pdf`

**optimization-report.blade.php**: inline CSS only (dompdf cannot fetch external resources in queued jobs); renders all section types; per-section disclaimer bar (yellow, left-bordered) and document-level footer disclaimer (RPT-03); severity badges; docs-missing table; refusal registry; year-end grouped items; glossary; masthead with brand, year badge, generated date.
